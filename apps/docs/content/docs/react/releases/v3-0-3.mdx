### useTheme hook

For plain React with Vite or Create React App (no Next.js theme provider), import `useTheme` from `@heroui/react`. It persists the choice in `localStorage`, writes `data-theme` and the theme id on `<html>` (`light`, `dark`, a custom id, or `system`), and applies the resolved `light` or `dark` class—including when `system` tracks `prefers-color-scheme`—or your custom theme.

```tsx
"use client";

import { ThemeProps, useTheme } from "@heroui/react";

export function ThemeSwitch() {
  // The default theme is `ThemeProps.SYSTEM`
  // Example: override the default system theme with a light theme
  const { theme, setTheme } = useTheme(ThemeProps.LIGHT);

  return (
    <div className="flex gap-2">
      <button onClick={() => setTheme(ThemeProps.LIGHT)}>
        Light
      </button>
      <button onClick={() => setTheme(ThemeProps.DARK)}>
        Dark
      </button>
      <button onClick={() => setTheme(ThemeProps.SYSTEM)}>
        System
      </button>
      <button onClick={() => setTheme('your-custom-theme')}>
        Custom Theme
      </button>
      <span className="text-sm opacity-70">Current: {theme}</span>
    </div>
  );
}
```

### DOM polymorphic utility

The DOM polymorphic helper lets lightweight components that are not built on React Aria primitives change their host element through a render prop.

**Example:** rendering a Card component as `<button />`

```tsx
<Card<"button"> render={(props) => <button {...props} />} />
```
