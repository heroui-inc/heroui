Draft patch release: [Button](/docs/components/button), Menu, and Dropdown apply compositor hints only while animating so labels stay sharp after a [Modal](/docs/components/modal) reopens, and a nested [Drawer](/docs/components/drawer) handle now closes only its own drawer. A [Table](/docs/components/table) keyboard-navigation fix is pending for this patch.

## Bug Fixes

- **Button, Menu, and Dropdown**: Scope `will-change` compositor hints to pressed and enter/exit animation states so static labels remain sharp inside transformed overlays, including after a `Modal` closes and reopens ([#6779](https://github.com/heroui-inc/heroui/pull/6779)).
- **Drawer**: Scope drag gestures to the nearest owning `Drawer.Dialog` so a nested drawer handle closes only its own drawer while the parent stays open and unshifted ([#6780](https://github.com/heroui-inc/heroui/pull/6780)).
- **Table (pending)**: Keep typeahead from stealing keystrokes and focus from nested editable controls. The pending fix exposes `keyboardNavigationBehavior` as a prop and defaults it to `"tab"` while preserving typeahead in non-editable cells; it is expected for v3.2.5 but has not merged yet ([#6781](https://github.com/heroui-inc/heroui/pull/6781)).
