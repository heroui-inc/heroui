## Features

### Select

[Select](/docs/components/select) adds a clear affordance without nesting buttons inside `Select.Trigger`. Compose `Select.ClearButton` next to the value and indicator, and listen with the root `onClear` prop. The control renders as a pointer-only `span` (`aria-hidden`); keyboard and screen reader users clear with `Backspace` or `Delete` when the clear button is composed and the popover is closed.

- **Clear button**: Add `Select.ClearButton` and root `onClear` so selections can be cleared without invalid nested buttons ([#6796](https://github.com/heroui-inc/heroui/pull/6796)).

## Bug Fixes

- **Overlays**: Raise `Modal`, `AlertDialog`, and `Drawer` to the shared overlay z-index and disable pointer events on exiting popover-level overlays so closing `Dropdown` / `Select` / `Popover` layers no longer cover or intercept clicks on a newly opened modal ([#6798](https://github.com/heroui-inc/heroui/pull/6798)).
- **Tag**: Expand the remove-button pressable area to 24×24 while keeping the 12×12 glyph, so taps on multi-select `Autocomplete` chips land reliably ([#6797](https://github.com/heroui-inc/heroui/pull/6797)).
- **Button, Menu, and Dropdown**: Scope `will-change` compositor hints to pressed and enter/exit animation states so static labels remain sharp inside transformed overlays, including after a `Modal` closes and reopens ([#6779](https://github.com/heroui-inc/heroui/pull/6779)).
- **Drawer**: Scope drag gestures to the nearest owning `Drawer.Dialog` so a nested drawer handle closes only its own drawer while the parent stays open and unshifted ([#6780](https://github.com/heroui-inc/heroui/pull/6780)).
- **Table**: Keep typeahead from stealing keystrokes and focus from nested editable controls. `keyboardNavigationBehavior` is now exposed as a prop and defaults to `"tab"`, while typeahead remains available in non-editable cells ([#6781](https://github.com/heroui-inc/heroui/pull/6781)).
- **NumberField**: Size the input grid from the stepper slots that are present, so fields without increment or decrement buttons no longer reserve empty side columns ([#6778](https://github.com/heroui-inc/heroui/pull/6778)).
- **Toast**: Merge custom `style` props with region CSS variables and toast stacking styles so passing styles such as `zIndex` no longer drops `--toast-width` and collapses the toast ([#6794](https://github.com/heroui-inc/heroui/pull/6794)).
