Patch release: `@heroui/react` and `@heroui/styles` move to `tailwind-variants@4.0.2`. [ToggleButton](/docs/components/toggle-button) gains a `fullWidth` prop, [Sheet](/docs/components/sheet) now stacks on the shared overlay z-index so it opens above a [Modal](/docs/components/modal), and footer actions in [Modal](/docs/components/modal), [AlertDialog](/docs/components/alert-dialog), [Drawer](/docs/components/drawer), and [Sheet](/docs/components/sheet) wrap instead of overflowing. This release also widens the [Table](/docs/components/table) column resizer hit area and clears a stale [ScrollShadow](/docs/components/scroll-shadow) fade when content stops overflowing.

## Dependencies

- **tailwind-variants**: Upgrade `@heroui/react` and `@heroui/styles` to `tailwind-variants@4.0.2`. HeroUI's internal `tv` wrapper now uses `createTV` with the built-in `twMerge` config, and the unused `tailwind-merge` Rollup external is removed. If your app imports `tailwind-variants` directly and passes `twMergeConfig`, note that v4 moves that option to `tailwind-variants/config` ([#6996](https://github.com/heroui-inc/heroui/pull/6996), [#7010](https://github.com/heroui-inc/heroui/pull/7010)).
- **Tooling**: Bump Tailwind CSS to `4.3.5`, Vitest to `5.1.0`, Storybook to `10.6.6`, and other development dependencies ([#7004](https://github.com/heroui-inc/heroui/pull/7004), [d7f820d](https://github.com/heroui-inc/heroui/commit/d7f820df5)).
- **Security**: Remove the vulnerable `deepmerge` package from the build toolchain (GHSA-gcqx-w48m-w2h4) and the unused `@vercel/og` dependency from the docs (GHSA-wx4j-mvgx-mqwp) ([#6997](https://github.com/heroui-inc/heroui/pull/6997)).

## What's New

- **ToggleButton**: Add `fullWidth` to stretch the button to the width of its container. It works with every `variant` and `size`, and maps to the `toggle-button--full-width` modifier ([#7012](https://github.com/heroui-inc/heroui/pull/7012)).

## Bug Fixes

- **Sheet**: Stack the overlay on the shared `--z-index-overlay` value used by [Modal](/docs/components/modal), [AlertDialog](/docs/components/alert-dialog), and [Drawer](/docs/components/drawer) instead of `z-50`, so a Sheet opened from inside a Modal renders above it ([#7006](https://github.com/heroui-inc/heroui/pull/7006)).
- **Overlay footers**: Wrap footer actions that do not fit on one row in [AlertDialog](/docs/components/alert-dialog), [Modal](/docs/components/modal), [Drawer](/docs/components/drawer), and [Sheet](/docs/components/sheet) instead of overflowing the panel ([#7001](https://github.com/heroui-inc/heroui/pull/7001)).
- **Table**: Make the column resizer a 24px-wide, full-height hit area lifted above the next header, so its far half is no longer covered. The visible line now draws with `::before` and stays centered on the column edge in RTL ([#7007](https://github.com/heroui-inc/heroui/pull/7007)).
- **ScrollShadow**: Clear the scroll-driven fade when content that overflowed, was scrolled, and then shrank to fit stops overflowing. Chromium and WebKit kept the last fade values on the inactive scroll timeline, leaving a stale edge fade ([#7015](https://github.com/heroui-inc/heroui/pull/7015)).
