Patch release: [Select](/docs/components/select), [Dropdown](/docs/components/dropdown), [Autocomplete](/docs/components/autocomplete), and [ComboBox](/docs/components/combo-box) popovers nest their corner radius with the item padding and keep the selection indicator off short labels. [AvatarGroup](/docs/components/avatar-group) clip overlap follows the avatar's own radius. [Modal](/docs/components/modal) and [Drawer](/docs/components/drawer) backdrops cover the reserved scrollbar gutter. [Checkbox](/docs/components/checkbox) keeps its checkmark mounted so the draw animation no longer flashes, and [ScrollShadow](/docs/components/scroll-shadow) no longer paints a seam at fractional device pixel ratios.

## Bug Fixes

- **List popovers**: Nest the outer radius with the item padding. The popover used `--radius-3xl` (24px), which is rounder than a 16px item sitting inside 6px of list padding, so the corner gap was tighter than the gap along the sides. The radius is now the item radius plus that padding, still capped at 32px, on [Select](/docs/components/select), [Dropdown](/docs/components/dropdown), [Autocomplete](/docs/components/autocomplete), and [ComboBox](/docs/components/combo-box) ([#6916](https://github.com/heroui-inc/heroui/pull/6916)).
- **Picker indicators**: Keep the checkmark off the label. `px-2.5` on [Select](/docs/components/select), [ComboBox](/docs/components/combo-box), and [Autocomplete](/docs/components/autocomplete) items was loaded after the `pe-7` that reserves room for `ListBox.ItemIndicator`, so a popover sized to its content painted the indicator on top of short labels. Items that contain an indicator now re-assert `pe-7` ([#6908](https://github.com/heroui-inc/heroui/pull/6908)).
- **AvatarGroup**: Clip overlap follows the avatar radius. The default `clip` mask cut a circle of `--avatar-size / 2`, which only clears the middle of each flat edge when a themed `--radius` makes the avatars rounded squares. [Avatar](/docs/components/avatar) now publishes `--avatar-radius`, and the group cuts a rounded rect grown by the seam width. Circular avatars still resolve to the same circle ([#6884](https://github.com/heroui-inc/heroui/pull/6884)).
- **Overlays**: Extend [Modal](/docs/components/modal) and [Drawer](/docs/components/drawer) backdrops across the scrollbar gutter React Aria reserves. The dimmed layer previously stopped short of the viewport edge on platforms with classic scrollbars, leaving an undimmed strip. The gutter width defaults to `0px`, so overlay scrollbars (macOS, mobile) are unchanged, and logical properties keep the extension on the correct side in RTL ([#6891](https://github.com/heroui-inc/heroui/pull/6891)).
- **Checkbox**: Keep the checkmark SVG mounted across state changes so its `strokeDashoffset` draw animation has a start frame. Clearing or toggling an indeterminate [Table](/docs/components/table) selection checkbox was replacing the line with a freshly mounted checkmark, which flashed. The indeterminate line is now overlaid only while indeterminate ([#6890](https://github.com/heroui-inc/heroui/pull/6890)).
- **ScrollShadow**: Remove the 1px seam the fade mask paints through content at fractional device pixel ratios (for example 125% display scaling). The gradient layer and the opaque scrollbar lane split a device pixel, and the two partial coverages composited to less than full opacity. The gradient now covers the whole box and the lane stays opaque on top, in both orientations and in controlled mode ([#6914](https://github.com/heroui-inc/heroui/pull/6914)).
- **Radio**: Pair `:focus-visible`, `:hover`, and `:active` with the existing `data-*` state rules, with hover behind `@media (hover: hover)`, so [Radio](/docs/components/radio) styling holds before hydration ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).
- **Toast**: Pair `data-*` attributes with the existing `:focus-visible` and `:hover` rules on [Toast](/docs/components/toast) ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).

## Styles

- **Disclosure**: Remove a stray `.accordion__heading` rule from `disclosure.css`. [Accordion](/docs/components/accordion) heading layout stays in `accordion.css` ([#6904](https://github.com/heroui-inc/heroui/pull/6904)).
- **Chip**: Empty `.chip--md`. It re-declared the `text-xs` already set on the base `.chip` class ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).

## Components

- **Display names**: Set `displayName` on component parts to `HeroUI.Component.SubPart`, matching the compound export path, and correct seven that did not (`HeroUI.ToastTitle` and the other flat Toast names, plus `AutocompleteTrigger`). Shared parts keep the name of the module that defines them. `toast.*`, `Toast.Queue`, and `Table.Collection` stay unnamed — the first two are not components, and `Table.Collection` is React Aria's `Collection` ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).
- **EmptyState**: Add the missing `"use client"` directive ([#6879](https://github.com/heroui-inc/heroui/pull/6879)).
