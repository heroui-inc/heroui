HeroUI v3 is built on [React Aria](https://react-aria.adobe.com/), so keyboard navigation, date and number formatting and layout direction follow the active locale. HeroUI's styles use logical properties (`ms-*`, `pe-*`, `start-*`, `rounded-s-*`), so components mirror automatically when the document direction is `rtl`.

## Setting the direction

Set `lang` and `dir` on the `<html>` element, and wrap your app in `I18nProvider` so React Aria uses the same locale. `isRTL` tells you which direction a locale uses.

```tsx
import {I18nProvider, isRTL} from "@heroui/react";

const locale = "fa-IR"; // or "ar-AE", "ur-PK", "he-IL"

export function App({children}) {
  return (
    <html dir={isRTL(locale) ? "rtl" : "ltr"} lang={locale}>
      <body>
        <I18nProvider locale={locale}>{children}</I18nProvider>
      </body>
    </html>
  );
}
```

<Callout type="info">
  Setting only `dir="rtl"` mirrors the layout, but React Aria still uses the browser locale for keyboard behavior and formatting. Set both `dir` and `I18nProvider` so they agree.
</Callout>

For a server-rendered setup, see [Frameworks → Locale Setup](/docs/react/getting-started/frameworks).

## Persian, Arabic and Urdu

| Language | Locale | Direction | Default calendar | Default digits |
| --- | --- | --- | --- | --- |
| Persian | `fa-IR` | RTL | Persian (Solar Hijri) | Persian (`۱۲۳`) |
| Arabic | `ar-AE`, `ar-SA`, `ar-EG`, … | RTL | Gregorian | Arabic or Latin, by region |
| Urdu | `ur-PK` | RTL | Gregorian | Latin |
| Hebrew | `he-IL` | RTL | Gregorian | Latin |

Date components such as `Calendar`, `DatePicker` and `DateRangePicker` render in the locale's default calendar. With `fa-IR`, they show the Persian calendar without extra setup.

### Choosing a calendar or numbering system

Use [Unicode locale extensions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Locale) to override the defaults:

```tsx
// Persian UI with the Gregorian calendar
<I18nProvider locale="fa-IR-u-ca-gregory">…</I18nProvider>

// Arabic UI with the Islamic civil calendar
<I18nProvider locale="ar-AE-u-ca-islamic-civil">…</I18nProvider>

// Persian UI with Latin digits
<I18nProvider locale="fa-IR-u-nu-latn">…</I18nProvider>
```

`onChange` on date components always returns a value in the same calendar system as `value` or `defaultValue` (Gregorian when none is given), whatever calendar the user sees.

### Built-in strings

React Aria ships translated accessibility strings (for example "Next month" or "Clear") for Arabic and Hebrew. Persian and Urdu are not in its translation set yet, so those strings fall back to English. Pass your own `aria-label` where a component accepts one if you need fully translated labels.

## Writing RTL-friendly styles

When you customize components, prefer logical utilities over physical ones so your overrides mirror too:

| Instead of | Use |
| --- | --- |
| `ml-*` / `mr-*` | `ms-*` / `me-*` |
| `pl-*` / `pr-*` | `ps-*` / `pe-*` |
| `left-*` / `right-*` | `start-*` / `end-*` |
| `rounded-l-*` / `rounded-r-*` | `rounded-s-*` / `rounded-e-*` |
| `text-left` / `text-right` | `text-start` / `text-end` |

For anything that has no logical equivalent, such as a directional icon, use Tailwind's `rtl:` variant:

```tsx
<Icon className="rtl:rotate-180" icon="gravity-ui:chevron-right" />
```
