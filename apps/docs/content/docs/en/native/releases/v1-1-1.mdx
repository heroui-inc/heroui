HeroUI Native v1.1.1 replaces `@gorhom/bottom-sheet` with native sheets through [`@lodev09/react-native-true-sheet`](https://sheet.lodev09.com): the sheet presentation controller on iOS and the native bottom sheet on Android. `BottomSheet` is now controlled through its ref and gains `Content`, `Header`, `Body` and `Footer` parts, and `presentation="bottom-sheet"` in Popover, Select and Menu uses the same native sheet. This release also rebuilds the Toast core so rapid toasts stay smooth, adds `maxToasts`, draws ScrollShadow fades with the native `backgroundImage` gradient, and fixes Dialog, Select and Switch bugs.

## Breaking Changes

### BottomSheet Uses Native Sheets

`BottomSheet` is now built on `@lodev09/react-native-true-sheet` instead of `@gorhom/bottom-sheet`. The sheet is opened and closed through its ref, its props move from `BottomSheet.Content` to `BottomSheet` itself, and the portal and overlay parts are gone because the sheet presents and dims itself.

**Before:**

```tsx
const [isOpen, setIsOpen] = useState(false);

<BottomSheet isOpen={isOpen} onOpenChange={setIsOpen}>
  <BottomSheet.Trigger asChild>
    <Button>Open</Button>
  </BottomSheet.Trigger>
  <BottomSheet.Portal>
    <BottomSheet.Overlay />
    <BottomSheet.Content snapPoints={['40%', '80%']}>
      <BottomSheet.Close />
      <BottomSheet.Title>Terms of Service</BottomSheet.Title>
      <BottomSheet.Description>...</BottomSheet.Description>
    </BottomSheet.Content>
  </BottomSheet.Portal>
</BottomSheet>;
```

**After:**

```tsx
const sheetRef = useRef<BottomSheetRef>(null);

<Button onPress={() => sheetRef.current?.present()}>Open</Button>
<BottomSheet ref={sheetRef} detents={[0.4, 0.8]}>
  <BottomSheet.Content>
    <BottomSheet.Header>
      <BottomSheet.Title>Terms of Service</BottomSheet.Title>
      <BottomSheet.Description>...</BottomSheet.Description>
      <BottomSheet.Close />
    </BottomSheet.Header>
    <BottomSheet.Body>...</BottomSheet.Body>
  </BottomSheet.Content>
</BottomSheet>;
```

| Before                                            | Now                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------ |
| `isOpen` / `onOpenChange` / `BottomSheet.Trigger` | `ref.present()` / `ref.dismiss()` and `onDidDismiss`               |
| `BottomSheet.Portal`, `BottomSheet.Overlay`       | Not needed: the sheet presents natively and dims (or blurs) itself |
| `BottomSheet.Content` sheet props                 | Props on `BottomSheet` itself; `className` stays on `Content`      |
| `snapPoints={['40%', '80%']}`                     | `detents={[0.4, 0.8]}`                                             |
| `enableDynamicSizing`                             | `detents={['auto']}` (the default)                                 |
| `enablePanDownToClose={false}`                    | `dismissible={false}`                                              |
| `BottomSheetScrollView` / `BottomSheetFlatList`   | `ScrollView` / `FlatList` plus `scrollableRef`                     |
| `BottomSheetFooter` / `footerComponent`           | `<BottomSheet.Footer isSticky>` or the `footer` prop               |
| `useBottomSheetAwareHandlers`                     | Removed: the sheet handles the keyboard natively                   |
| `useBottomSheet()`                                | Removed: keep a ref to the sheet                                   |

**Migration:** Replace `@gorhom/bottom-sheet` with `@lodev09/react-native-true-sheet` (`^4.1.0`), rebuild the app, and update each `BottomSheet` using the table above. See the [BottomSheet migration guide](/docs/native/components/bottom-sheet#migrating-from-the-previous-bottomsheet).

**Related PR:** [#543](https://github.com/heroui-inc/heroui-native/pull/543)

### Bottom-Sheet Presentation in Popover, Select and Menu

`presentation="bottom-sheet"` keeps its API (open state, triggers, item selection and `contentContainerClassName` work as before), but gorhom-specific props passed to the content need their TrueSheet equivalents, for example `snapPoints={['35%']}` becomes `detents={[0.35]}`. In sheet mode, `usePopoverAnimation()`, `useSelectAnimation()` and `useMenuAnimation()` no longer track the sheet position; call `useBottomSheetAnimation()` inside the content instead.

**Before:**

```tsx
<Select.Content presentation="bottom-sheet" snapPoints={['35%']}>
```

**After:**

```tsx
<Select.Content presentation="bottom-sheet" detents={[0.35]}>
```

**Related PR:** [#543](https://github.com/heroui-inc/heroui-native/pull/543)

## What's New

### Native BottomSheet

`BottomSheet` now presents as a real native sheet, above everything including native modals and `formSheet` screens. Dragging, the keyboard and dimming are handled natively, so the JS portal, overlay and gesture layers are gone. ([#543](https://github.com/heroui-inc/heroui-native/pull/543))

**Features:**

- Ref methods `present()`, `resize()`, `dismiss()` and `dismissStack()`; sheets can also be controlled by `name` with `useTrueSheet()` or `TrueSheet.present(name)`
- New compound parts `BottomSheet.Content`, `BottomSheet.Header`, `BottomSheet.Body` and `BottomSheet.Footer`, matching `Card`; `isSticky` on Header or Footer pins it while the body scrolls
- `detents` replaces `snapPoints`, with `'auto'` (the default) sizing the sheet to its content
- `dimBlur` blurs the screen behind the sheet instead of dimming it
- Stacked sheets, with Dialog and Toast staying visible above a presented sheet
- `useBottomSheetAnimation()` exposes live Reanimated values (position, detent, index and a 0–1 `progress`) for animating content with the sheet
- Gesture-handler components such as `Slider` work inside sheets on Android
- Sheets as routes through TrueSheet's Expo Router navigator
- The glass theme keeps the platform's own sheet material (Liquid Glass on iOS 26); other themes use the `overlay` color
- Sheets are in the accessibility tree on both platforms, and nothing covers the app's tree while no sheet is open, which fixes VoiceOver ([#372](https://github.com/heroui-inc/heroui-native/issues/372)) and Maestro ([#353](https://github.com/heroui-inc/heroui-native/issues/353)) issues with the old sheet

**Usage:**

```tsx
import { BottomSheet, Button, type BottomSheetRef } from 'heroui-native';
import { useRef } from 'react';

export function Example() {
  const sheetRef = useRef<BottomSheetRef>(null);

  return (
    <>
      <Button onPress={() => sheetRef.current?.present()}>Open</Button>
      <BottomSheet ref={sheetRef} detents={['auto', 0.9]}>
        <BottomSheet.Content>
          <BottomSheet.Header isSticky>
            <BottomSheet.Title>Terms of Service</BottomSheet.Title>
            <BottomSheet.Close />
          </BottomSheet.Header>
          <BottomSheet.Body>...</BottomSheet.Body>
          <BottomSheet.Footer isSticky>
            <Button onPress={() => sheetRef.current?.dismiss()}>Accept</Button>
          </BottomSheet.Footer>
        </BottomSheet.Content>
      </BottomSheet>
    </>
  );
}
```

For complete documentation and examples, see the [BottomSheet component page](/docs/native/components/bottom-sheet).

### Toast Rebuilt for Rapid Toasts

The Toast core is rebuilt around an external store with stack layout on the UI thread, so calling `toast.show()` many times in a row stays smooth, mostly on Android. Only the visible stack plus one toast behind it is mounted, and toasts already on screen no longer re-render when a new one arrives. The `toast.show` / `toast.hide` / `useToast` API is unchanged. ([#544](https://github.com/heroui-inc/heroui-native/pull/544))

A new opt-in `maxToasts` option on the toast provider config drops the oldest toasts past a limit. With `maxToasts: 1`, every new toast replaces the previous one:

```tsx
<HeroUINativeProvider config={{ toast: { maxToasts: 1 } }}>
  {children}
</HeroUINativeProvider>
```

### ScrollShadow Without a Gradient Library

`ScrollShadow` now draws its fades with the native `backgroundImage` style (`linear-gradient`), so `expo-linear-gradient` or similar libraries are no longer needed. On React Native 0.81–0.86 it falls back to `experimental_backgroundImage` automatically. `LinearGradientComponent` is now optional and deprecated; passing it keeps the previous rendering. ([#546](https://github.com/heroui-inc/heroui-native/pull/546))

```tsx
<ScrollShadow>
  <ScrollView>...</ScrollView>
</ScrollShadow>
```

### CloseButton Accessibility Label

`CloseButton` (used by `BottomSheet.Close`, `Dialog.Close` and others) is now announced as "Close" by screen readers instead of an unlabelled button. Pass `aria-label` to change it. ([#543](https://github.com/heroui-inc/heroui-native/pull/543))

## Bug Fixes

This release includes fixes for the following issues:

- **[Issue #369](https://github.com/heroui-inc/heroui-native/issues/369)**: Swipe-to-dismiss on Toast did not work on Android, and a strip of the previous toast's text showed through the front toast while it scaled. Each toast now has its own gesture root, and the covers are drawn as sibling views. ([#544](https://github.com/heroui-inc/heroui-native/pull/544))
- **Toast** could render under the navigation bar in Android landscape. Toasts now stay inside it. ([#544](https://github.com/heroui-inc/heroui-native/pull/544))
- **Dialog** and Select with `presentation="dialog"`: releasing after an upward or short downward drag made the content jump before settling. A release that doesn't dismiss now eases straight back to rest. ([#545](https://github.com/heroui-inc/heroui-native/pull/545))
- **Select.Overlay** faded out while the dialog presentation was dragged upward. The dim layer now stays during the drag. ([#545](https://github.com/heroui-inc/heroui-native/pull/545))
- **[Issue #542](https://github.com/heroui-inc/heroui-native/issues/542)**: The Switch thumb could stay at the leading edge on Uniwind versions below 1.10, and an initially selected switch could briefly start on the wrong side. The static thumb inset is removed so the animation owns the position, including in RTL. ([#547](https://github.com/heroui-inc/heroui-native/pull/547))
- **Example app**: the horizontal ScrollShadow demo rendered blank in Arabic and Hebrew. ([#548](https://github.com/heroui-inc/heroui-native/pull/548))
