补丁版本：全新的 [Agent Bridge](/docs/react/getting-started/agent-bridge)（`@heroui/react/agent`）让 AI 代理可以通过组件读取并操作运行中的 HeroUI 应用；`@heroui/react` 现在随包附带与版本匹配的 Markdown 文档，供编码代理读取；全新的 `heroui-theming` 技能让代理可以重新设计 HeroUI 样式或创建完整主题（[使用代理定制主题](/docs/react/getting-started/theming-for-agents)）。`@heroui/react` 与 `@heroui/styles` 升级至 `tailwind-variants@4.0.2`。[ToggleButton](/docs/components/toggle-button) 新增 `fullWidth` 属性；[Sheet](/docs/components/sheet) 改用共享的浮层 z-index，因此可以显示在 [Modal](/docs/components/modal) 之上；[Modal](/docs/components/modal)、[AlertDialog](/docs/components/alert-dialog)、[Drawer](/docs/components/drawer) 与 [Sheet](/docs/components/sheet) 的底部操作在空间不足时会换行而不再溢出。[ProgressBar](/docs/components/progress-bar) 与 [Skeleton](/docs/components/skeleton) 的动画在 RTL 下会按阅读方向扫动。本版本还加宽了 [Table](/docs/components/table) 列宽调整手柄的点击区域，修复 [Checkbox](/docs/components/checkbox) 不确定状态填充的闪烁，让 [Dropdown](/docs/components/dropdown) 菜单与 [ListBox](/docs/components/list-box) 选项中的图标和长标签保持正常布局，让触屏设备上的 `variant="blur"` 背景保持模糊，并修复内容不再溢出时 [ScrollShadow](/docs/components/scroll-shadow) 残留的渐隐效果。

</Callout>

## 依赖

- **tailwind-variants**：将 `@heroui/react` 与 `@heroui/styles` 升级至 `tailwind-variants@4.0.2`。HeroUI 内部的 `tv` 封装改用 `createTV` 与内置的 `twMerge` 配置，并移除不再使用的 `tailwind-merge` Rollup external。如果你的应用直接引入 `tailwind-variants` 并传入 `twMergeConfig`，请注意 v4 已将该选项移至 `tailwind-variants/config`（[#6996](https://github.com/heroui-inc/heroui/pull/6996)、[#7010](https://github.com/heroui-inc/heroui/pull/7010)）。

## 新功能

- **Agent Bridge**：从新的 `@heroui/react/agent` 入口引入 `createAgent`，为 AI 代理提供操作运行中应用的三个工具：`snapshot` 列出页面上的组件，`act` 按标签使用组件（例如 `setValue`、`setChecked`、`press`），`query` 搜索组件。Bridge 读取 HeroUI 已渲染的角色、标签与状态，无需修改组件。它提供用于权限控制的 `allow` 回调以及 `data-agent-confirm`、`data-agent-hidden`、`data-agent-secret` 标记、变更订阅、面向模型 SDK 的 `agentTools` 与 `callAgentTool`、面向 WebMCP 的 `registerTools`，以及用于自定义组件的 `useAgentComponent`。参见 [Agent Bridge](/docs/react/getting-started/agent-bridge) 与 [Agent Bridge 参考](/docs/react/getting-started/agent-bridge-reference)（[#7018](https://github.com/heroui-inc/heroui/pull/7018)）。
- **包内文档**：`@heroui/react` 现在在 `node_modules/@heroui/react/docs/` 下以 Markdown 形式附带文档，包括 `llms.txt` 索引以及组件和指南页面，在发布时由文档站生成。编码代理可以离线读取与项目所装版本一致的文档。在 `AGENTS.md` 或 `CLAUDE.md` 中让代理先读取 `docs/llms.txt`；参见 [LLMs.txt](/docs/react/getting-started/llms-txt)（[#7017](https://github.com/heroui-inc/heroui/pull/7017)）。
- **heroui-theming 技能**：新的代理技能，支持通过令牌、BEM 覆盖以及具名的亮色与暗色主题进行全局定制和完整主题创作，适用于 React 或任意框架。使用 `curl -fsSL https://heroui.com/install | bash -s heroui-theming` 安装；参见 [使用代理定制主题](/docs/react/getting-started/theming-for-agents)（[#7017](https://github.com/heroui-inc/heroui/pull/7017)）。
- **heroui-react 技能**：当项目依赖 `@heroui/react` 时，从已安装的包中读取组件文档与指南，否则回退到 heroui.com（[#7017](https://github.com/heroui-inc/heroui/pull/7017)）。
- **ToggleButton**：新增 `fullWidth`，让按钮撑满容器宽度。适用于所有 `variant` 与 `size`，对应 `toggle-button--full-width` 修饰符（[#7012](https://github.com/heroui-inc/heroui/pull/7012)）。

## 错误修复

- **Checkbox**：始终挂载不确定状态指示器，使其填充在不确定状态变化时淡入淡出而不再闪烁，包括 [Table](/docs/components/table) 中的全选复选框（[#7019](https://github.com/heroui-inc/heroui/pull/7019)）。
- **Menu 与 ListBox 选项**：防止图标被压缩，并让长标签（包括标签与描述组合中的标签）换行而不再溢出选项，适用于 Menu、[Dropdown](/docs/components/dropdown)、[ListBox](/docs/components/list-box) 与 [Select](/docs/components/select)（[#7034](https://github.com/heroui-inc/heroui/pull/7034)）。
- **模糊背景**：在触屏设备上，仅在 [Modal](/docs/components/modal)、[AlertDialog](/docs/components/alert-dialog) 或 [Drawer](/docs/components/drawer) 的背景进入或退出时跳过 `backdrop-filter`，使 `variant="blur"` 在浮层打开后不再显得不透明（[#7025](https://github.com/heroui-inc/heroui/pull/7025)）。
- **Sheet**：浮层改用与 [Modal](/docs/components/modal)、[AlertDialog](/docs/components/alert-dialog)、[Drawer](/docs/components/drawer) 共享的 `--z-index-overlay`，取代 `z-50`，使在 Modal 内打开的 Sheet 显示在其上方（[#7006](https://github.com/heroui-inc/heroui/pull/7006)）。
- **浮层底部**：[AlertDialog](/docs/components/alert-dialog)、[Modal](/docs/components/modal)、[Drawer](/docs/components/drawer) 与 [Sheet](/docs/components/sheet) 的底部操作在一行放不下时自动换行，不再溢出面板（[#7001](https://github.com/heroui-inc/heroui/pull/7001)）。
- **Table**：列宽调整手柄改为 24px 宽、全高的点击区域，并提升至下一个表头之上，远端一半不再被遮挡。可见的分隔线改由 `::before` 绘制，并在 RTL 下保持在列边缘居中（[#7007](https://github.com/heroui-inc/heroui/pull/7007)）。
- **ScrollShadow**：当内容曾经溢出并被滚动、随后缩小到不再溢出时，清除滚动驱动的渐隐效果。此前 Chromium 与 WebKit 会在失效的滚动时间线上保留最后的渐隐值，导致边缘残留渐隐（[#7015](https://github.com/heroui-inc/heroui/pull/7015)）。

## 样式

- **RTL 动画**：[ProgressBar](/docs/components/progress-bar) 的不确定进度扫动与 [Skeleton](/docs/components/skeleton) 的闪光效果在 RTL 下改为从右向左。每个动画只保留一个关键帧，并按通过 `rtl` 变体设置的方向符号缩放，因此减少动效、自定义 `--animate-skeleton` 以及嵌套的 `dir="ltr"` 子树都能正常工作（[#7023](https://github.com/heroui-inc/heroui/pull/7023)）。

- **Agent Bridge**：新增 [Agent Bridge](/docs/react/getting-started/agent-bridge) 指南与 [Agent Bridge 参考](/docs/react/getting-started/agent-bridge-reference)（[#7018](https://github.com/heroui-inc/heroui/pull/7018)）。
- **使用代理定制主题**：新增指南，介绍如何借助编码代理全局定制 HeroUI 并创建完整主题，并在 [LLMs.txt](/docs/react/getting-started/llms-txt) 与 [Agent Skills](/docs/react/getting-started/agent-skills) 页面中说明包内文档（[#7017](https://github.com/heroui-inc/heroui/pull/7017)）。
- **DESIGN.md**：发布 React 与 Native 的默认主题 `DESIGN.md` 文件，并为 CLI 的 `design-md` 命令补充文档。参见 [DESIGN.md](/docs/react/getting-started/design-md) 与 [CLI](/docs/react/getting-started/cli)（[#6905](https://github.com/heroui-inc/heroui/pull/6905)、[#6992](https://github.com/heroui-inc/heroui/pull/6992)、[#6994](https://github.com/heroui-inc/heroui/pull/6994)）。

- **搜索**：当搜索内容像一个问题时优先列出 Ask AI，并移除搜索对话框中的分隔线（[#6990](https://github.com/heroui-inc/heroui/pull/6990)、[#6991](https://github.com/heroui-inc/heroui/pull/6991)）。
