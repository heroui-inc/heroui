## 错误修复

- **列表浮层**：外层圆角与选项内边距对齐。浮层原先使用 `--radius-3xl`（24px），比放在 6px 列表内边距里的 16px 选项更圆，因此角落间隙比侧边更紧。现在圆角等于选项圆角加上这段内边距，上限仍为 32px，作用于 [Select](/docs/components/select)、[Dropdown](/docs/components/dropdown)、[Autocomplete](/docs/components/autocomplete) 与 [ComboBox](/docs/components/combo-box) ([#6916](https://github.com/heroui-inc/heroui/pull/6916))。
- **选择指示器**：勾选标记不再压住标签。[Select](/docs/components/select)、[ComboBox](/docs/components/combo-box) 与 [Autocomplete](/docs/components/autocomplete) 选项上的 `px-2.5` 在为 `ListBox.ItemIndicator` 预留空间的 `pe-7` 之后加载，内容自适应宽度的浮层会把指示器画在短标签上面。包含指示器的选项现在重新声明 `pe-7` ([#6908](https://github.com/heroui-inc/heroui/pull/6908))。
- **AvatarGroup**：裁切重叠跟随头像圆角。默认的 `clip` 遮罩按 `--avatar-size / 2` 切出一个圆。当主题 `--radius` 把头像变成圆角矩形时，这个圆只清掉每条直边的中段。[Avatar](/docs/components/avatar) 现在公开 `--avatar-radius`，组按接缝宽度切出圆角矩形。圆形头像仍解析为同一个圆 ([#6884](https://github.com/heroui-inc/heroui/pull/6884))。
- **Checkbox**：勾选标记的 SVG 在状态切换时保持挂载，使 `strokeDashoffset` 绘制动画有起始帧。清除或切换 [Table](/docs/components/table) 中不确定状态的选择复选框时，原先会用新挂载的勾选标记替换横线，从而产生闪烁。不确定状态的横线现在只在该状态下叠加显示 ([#6890](https://github.com/heroui-inc/heroui/pull/6890))。
- **ScrollShadow**：移除淡出遮罩在非整数设备像素比（例如 125% 显示缩放）下穿过内容的 1px 接缝。渐变层与不透明的滚动条通道会切开同一个设备像素，两层的部分覆盖合成后透明度不足。现在渐变覆盖整个盒子，通道保持不透明并叠在上面，两个方向以及受控模式都适用 ([#6914](https://github.com/heroui-inc/heroui/pull/6914))。
- **Radio**：为现有的 `data-*` 状态规则补上 `:focus-visible`、`:hover` 与 `:active`，悬停放在 `@media (hover: hover)` 之后，使 [Radio](/docs/components/radio) 在水合之前也保持样式 ([#6879](https://github.com/heroui-inc/heroui/pull/6879))。
- **Toast**：为 [Toast](/docs/components/toast) 现有的 `:focus-visible` 与 `:hover` 规则补上对应的 `data-*` 属性 ([#6879](https://github.com/heroui-inc/heroui/pull/6879))。

## 样式

- **Disclosure**：从 `disclosure.css` 中移除误放的 `.accordion__heading` 规则。[Accordion](/docs/components/accordion) 标题的布局仍由 `accordion.css` 负责 ([#6904](https://github.com/heroui-inc/heroui/pull/6904))。
- **Chip**：清空 `.chip--md`。它重复声明了基础 `.chip` 上已有的 `text-xs` ([#6879](https://github.com/heroui-inc/heroui/pull/6879))。

## 组件

- **displayName**：将组件各部分的 `displayName` 设为 `HeroUI.Component.SubPart`，与复合导出路径一致，并修正 7 个不符合该约定的名称（`HeroUI.ToastTitle` 及其他扁平的 Toast 名称，以及 `AutocompleteTrigger`）。共享部分保留定义它们的模块名称。`toast.*`、`Toast.Queue` 与 `Table.Collection` 保持不命名——前两者不是组件，`Table.Collection` 则是 React Aria 的 `Collection` ([#6879](https://github.com/heroui-inc/heroui/pull/6879))。
- **EmptyState**：补上缺失的 `"use client"` 指令 ([#6879](https://github.com/heroui-inc/heroui/pull/6879))。
