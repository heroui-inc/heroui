## 新增内容

### Table.SortableColumnHeader

`Table.SortableColumnHeader` 用于渲染 sortable 列标题和可选的升降序指示器。放在 `Table.Column` render prop 中，并传入 `sortDirection` ([#6588](https://github.com/heroui-inc/heroui/pull/6588))。

```tsx
<Table.Column allowsSorting>
  {({sortDirection}) => (
    <Table.SortableColumnHeader sortDirection={sortDirection}>
      Name
    </Table.SortableColumnHeader>
  )}
</Table.Column>
```

- **默认指示器**：存在排序方向时显示 chevron
- **自定义指示器**：传入 `indicator`，或用 `showIndicator={false}` 隐藏
- **样式插槽**：`.table__sortable-column-header` + `.table__sortable-column-indicator`

## 组件修复

- **Toast**：Toast 队列会串行化 ViewTransition 更新，避免 `toast.promise()` 关闭 loading toast 并打开 success/error toast 时出现 skipped transition 和 AbortError rejection ([#6511](https://github.com/heroui-inc/heroui/pull/6511))。
- **Fieldset**：`disabled` 现在会通过 React Aria Button、CheckboxGroup、Link、RadioGroup、Slider、ToggleButton 和 ToggleButtonGroup context 传递给后代组件 ([#6596](https://github.com/heroui-inc/heroui/pull/6596))。
- **Calendar 文档**：Calendar 与 RangeCalendar 已补充 `weeksInMonth`；RangeCalendar 现在列出 React Aria 1.18 的 `isDateUnavailable(date, anchorDate)` 签名 ([#6586](https://github.com/heroui-inc/heroui/pull/6586))。

## 样式修复

- **Modal / AlertDialog**：`scroll-inside` dialog 现在使用 `max-h-full min-h-0` 限制高度，让 body 区域滚动而不是让 dialog 溢出 ([#6597](https://github.com/heroui-inc/heroui/pull/6597))。
- **ScrollShadow**：Fade mask 通过 `--scroll-shadow-scrollbar-size` 为可见原生滚动条保留空间 ([#6598](https://github.com/heroui-inc/heroui/pull/6598))。
- **Table RTL**：列分隔线和 resize handle 在 RTL 布局中改用 logical `end-0` 定位 ([#6606](https://github.com/heroui-inc/heroui/pull/6606))。
