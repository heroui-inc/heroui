通过 [`@lodev09/react-native-true-sheet`](https://sheet.lodev09.com) 以原生方式呈现的底部弹层：iOS 上使用 sheet presentation controller，Android 上使用原生底部弹层。弹层位于所有内容之上，包括原生模态与 `formSheet` 页面。

## 安装

`BottomSheet` 需要 TrueSheet 包（HeroUI Native 的可选对等依赖）：

```bash
npx expo install @lodev09/react-native-true-sheet
```

它是原生模块，安装后需要重新构建应用。`Popover`、`Select` 与 `Menu` 的 `presentation="bottom-sheet"` 模式也使用同一个包。

## 导入

```tsx
import { BottomSheet, type BottomSheetRef } from 'heroui-native';
```

## 结构

```tsx
<BottomSheet ref={sheetRef}>
  <BottomSheet.Content>
    <BottomSheet.Header>
      <BottomSheet.Title>...</BottomSheet.Title>
      <BottomSheet.Description>...</BottomSheet.Description>
      <BottomSheet.Close />
    </BottomSheet.Header>
    <BottomSheet.Body>...</BottomSheet.Body>
    <BottomSheet.Footer>...</BottomSheet.Footer>
  </BottomSheet.Content>
</BottomSheet>
```

- **BottomSheet**：弹层本身。通过 ref 呈现之前不渲染任何内容；内容在首次呈现时挂载。
- **BottomSheet.Content**：为弹层添加内边距并承载各部件的对话框容器。其中可放置任意内容；Header、Body 与 Footer 均为可选。
- **BottomSheet.Header**：顶部区域，通常放置标题、描述与关闭按钮。`isSticky` 可在下方内容滚动时将其固定。
- **BottomSheet.Body**：主体区域。
- **BottomSheet.Footer**：底部区域，通常放置操作按钮。`isSticky` 可在上方内容滚动时将其固定。
- **BottomSheet.Close**：关闭弹层的按钮；可自定义子节点或使用默认关闭图标。
- **BottomSheet.Title**：弹层标题，具有标题角色，并与弹层关联以支持无障碍。
- **BottomSheet.Description**：弹层描述，并与弹层关联以支持无障碍。

## 用法

### 基础底部弹层

弹层通过 ref 控制：`present()`、`resize()`、`dismiss()` 与 `dismissStack()`。

```tsx
const sheetRef = useRef<BottomSheetRef>(null);

<Button onPress={() => sheetRef.current?.present()}>Open</Button>
<BottomSheet ref={sheetRef}>
  <BottomSheet.Content>
    <BottomSheet.Header className="mb-8 gap-2">
      <BottomSheet.Title>Keep yourself safe</BottomSheet.Title>
      <BottomSheet.Description>
        Update your software to the latest version.
      </BottomSheet.Description>
    </BottomSheet.Header>
    <BottomSheet.Footer>
      <Button onPress={() => sheetRef.current?.dismiss()}>Later</Button>
    </BottomSheet.Footer>
  </BottomSheet.Content>
</BottomSheet>
```

### 停靠点

`detents` 列出弹层可停留的尺寸，从小到大排列，最多 3 个。`'auto'`（默认值）按内容自适应弹层高度，`'peek'` 按页眉与页脚的高度设置，数字表示可用高度的比例（`0`–`1`）。

```tsx
<BottomSheet ref={sheetRef} detents={[0.4, 0.8]}>
  ...
</BottomSheet>;

sheetRef.current?.present(1); // open at the second detent
sheetRef.current?.resize(0); // move to the first detent
```

### 通过名称控制弹层

控制弹层不一定需要 ref。为弹层设置唯一的 `name`，即可在任意位置（其他组件、store、导航监听器）通过 TrueSheet 的命令式 API 控制它：`present`、`resize`、`dismiss`、`dismissStack` 与 `dismissAll`。

在组件内使用 `useTrueSheet()` hook。它在所有平台上都可用（在 Web 上需要 `TrueSheetProvider`，`HeroUINativeProvider` 已内置）：

```tsx
import { useTrueSheet } from '@lodev09/react-native-true-sheet';

function Controls() {
  const { present, resize, dismiss } = useTrueSheet();

  return (
    <>
      <Button onPress={() => present('filters')}>Open filters</Button>
      <Button onPress={() => resize('filters', 1)}>Expand</Button>
      <Button onPress={() => dismiss('filters')}>Close</Button>
    </>
  );
}

<BottomSheet name="filters" detents={[0.4, 0.8]}>
  ...
</BottomSheet>;
```

在 React 之外（store、服务、导航回调），调用 `TrueSheet` 上的静态方法。这些方法仅支持原生平台，需要支持 Web 时请使用 hook：

```tsx
import { TrueSheet } from '@lodev09/react-native-true-sheet';

await TrueSheet.present('filters'); // first detent
await TrueSheet.present('filters', 1); // second detent
await TrueSheet.resize('filters', 0);
await TrueSheet.dismiss('filters');
await TrueSheet.dismissAll();
```

每个方法都返回一个在动画结束后 resolve 的 Promise；如果没有已挂载的弹层使用该 `name`，则会抛出错误。已挂载弹层的名称必须唯一。

### 模糊遮罩

`dimBlur` 会将弹层背后的屏幕模糊化，而非遮暗，样式名称与 iOS 相同（`'dark'`、`'light'`、`'system-ultra-thin-material-dark'` 等）。`dimOpacity` 设置模糊强度。Android 12 及以上支持模糊；更早的 Android 版本会回退为着色遮罩。

```tsx
<BottomSheet
  ref={sheetRef}
  dimBlur="system-ultra-thin-material-dark"
  dimOpacity={0.4}
>
  ...
</BottomSheet>
```

### 固定页眉与页脚

在 `BottomSheet.Header` 或 `BottomSheet.Footer` 上设置 `isSticky`，可在中间内容滚动时将其固定在弹层顶部或底部。固定部件渲染在弹层原生的 header / footer 插槽中，其高度会计入 `auto` 停靠点。它必须是 `BottomSheet.Content` 的直接子元素；若被包裹在其他组件中，则会在原位置渲染。

将滚动视图放在 `BottomSheet.Body` 中，并将其 ref 传给 `scrollableRef`，使弹层能协调滚动与拖动、内边距及键盘：

```tsx
const scrollRef = useRef<ScrollViewInstance>(null);

<BottomSheet
  ref={sheetRef}
  detents={[0.6, 1]}
  scrollableRef={scrollRef}
  style={{ flex: 1 }}
>
  <BottomSheet.Content className="flex-1 px-0">
    <BottomSheet.Header isSticky className="pb-4">
      <BottomSheet.Title>Terms of Service</BottomSheet.Title>
    </BottomSheet.Header>
    <BottomSheet.Body className="flex-1">
      <ScrollView ref={scrollRef} contentContainerClassName="px-5">
        ...
      </ScrollView>
    </BottomSheet.Body>
    <BottomSheet.Footer isSticky>
      <Button onPress={() => sheetRef.current?.dismiss()}>Accept</Button>
    </BottomSheet.Footer>
  </BottomSheet.Content>
</BottomSheet>;
```

固定部件会取代 `header` / `footer` 属性。插槽中的其他内容请直接使用这两个属性，例如浮于内容之上的页脚（`footerOptions={{ position: 'absolute' }}`）。

### 文本输入

弹层会自动随键盘移动。若要让键盘与弹层同时弹出，请在 `onWillPresent` 中聚焦输入框：

```tsx
const inputRef = useRef<InputRef>(null);
const handleWillPresent = useCallback(() => inputRef.current?.focus(), []);

<BottomSheet ref={sheetRef} onWillPresent={handleWillPresent}>
  <BottomSheet.Content>
    <TextField>
      <Input ref={inputRef} placeholder="name@example.com" />
    </TextField>
  </BottomSheet.Content>
</BottomSheet>;
```

### 随弹层动画

`useBottomSheetAnimation()` 返回弹层的实时 Reanimated 值。请在弹层内容中调用：

```tsx
function SheetIcon() {
  const { progress } = useBottomSheetAnimation();
  const style = useAnimatedStyle(() => ({
    opacity: progress.get(),
    transform: [{ scale: interpolate(progress.get(), [0, 1], [0.4, 1]) }],
  }));

  return <Animated.View style={style}>...</Animated.View>;
}
```

`Popover`、`Select` 与 `Menu` 的 `presentation="bottom-sheet"` 内容同样渲染在 `BottomSheet` 中，因此该 hook 在其中也可使用。

### 将弹层作为导航页面

若要以路由方式打开弹层，请使用 TrueSheet 自带的导航器。配合 Expo Router：

```tsx
// app/sheet/_layout.tsx
import { Sheet } from '@lodev09/react-native-true-sheet/navigation/expo-router';

export const unstable_settings = { anchor: 'index' };

export default function SheetLayout() {
  return (
    <Sheet>
      <Sheet.Screen name="index" />
      <Sheet.Screen
        name="details"
        options={{ reanimated: true, detents: ['auto'] }}
      />
    </Sheet>
  );
}
```

`index` 作为普通页面渲染，其他路由均以弹层呈现。使用 `router.push()` 打开，使用 `router.back()`（或向下拖动）关闭。其根视图不应使用 `flex: 1`；弹层会根据内容自行确定尺寸。在 Android 上，使用手势处理器组件（如 `Slider`）的弹层路由需要包裹在 `flexGrow: 1` 的 `GestureHandlerRootView` 中；`BottomSheet` 会自行添加。导航器弹层是 TrueSheet 自己的弹层，因此无法在其中使用 `BottomSheet.Content`、`Title` 等部件。React Navigation 版本请参见 [TrueSheet 导航指南](https://sheet.lodev09.com)。

### 堆叠弹层

在一个弹层打开时呈现另一个弹层，会将其堆叠在上方。`dismiss()` 会关闭该弹层及堆叠在其上的所有弹层；`dismissStack()` 仅关闭其上方的弹层。

### 弹层之上的对话框与提示

`Dialog`、`Toast` 以及浮动的 `Popover`、`Select` 与 `Menu` 渲染在任何已呈现弹层之上的原生层中，因此从弹层内打开时仍保持可见。

## 示例

```tsx
import { BottomSheet, Button, type BottomSheetRef } from 'heroui-native';
import { useRef } from 'react';
import { View } from 'react-native';

export default function BottomSheetExample() {
  const sheetRef = useRef<BottomSheetRef>(null);

  return (
    <View className="flex-1 items-center justify-center">
      <Button variant="secondary" onPress={() => sheetRef.current?.present()}>
        Delete account
      </Button>
      <BottomSheet
        ref={sheetRef}
        onDidDismiss={() => console.log('sheet closed')}
      >
        <BottomSheet.Content>
          <BottomSheet.Header className="mb-8 gap-2">
            <BottomSheet.Title>Delete account?</BottomSheet.Title>
            <BottomSheet.Description>
              You won't be able to restore it or receive support.
            </BottomSheet.Description>
          </BottomSheet.Header>
          <BottomSheet.Footer className="gap-3">
            <Button
              variant="danger"
              onPress={() => sheetRef.current?.dismiss()}
            >
              Delete forever
            </Button>
            <Button
              variant="tertiary"
              onPress={() => sheetRef.current?.dismiss()}
            >
              Cancel
            </Button>
          </BottomSheet.Footer>
        </BottomSheet.Content>
      </BottomSheet>
    </View>
  );
}
```

## API 参考

### BottomSheet

转发除 `onPositionChange` 之外的所有 [TrueSheet 属性](https://sheet.lodev09.com/reference/configuration)（请改用 `useBottomSheetAnimation`）。最常用的属性：

| prop              | type                                 | default    | description                                                               |
| ----------------- | ------------------------------------ | ---------- | ------------------------------------------------------------------------- |
| `children`        | `React.ReactNode`                    | -          | 弹层内容，通常为 `BottomSheet.Content`                                    |
| `name`            | `string`                             | 自动生成   | 唯一名称，用于通过 `useTrueSheet()` / `TrueSheet.present(name)` 控制弹层  |
| `detents`         | `('auto' \| 'peek' \| number)[]`     | `['auto']` | 弹层可停留的尺寸，从小到大排列，最多 3 个                                 |
| `dimmed`          | `boolean`                            | `true`     | 是否遮暗弹层背后的屏幕                                                    |
| `dimOpacity`      | `number`                             | `0.5`      | 遮暗（或模糊）强度                                                        |
| `dimBlur`         | `BackgroundBlur`                     | -          | 将弹层背后的屏幕模糊化，而非遮暗                                          |
| `dismissible`     | `boolean`                            | `true`     | 是否可通过拖动、点击遮暗区域或 Android 返回键关闭弹层                     |
| `draggable`       | `boolean`                            | `true`     | 弹层是否可拖动                                                            |
| `grabber`         | `boolean`                            | `true`     | 是否显示拖动条                                                            |
| `backgroundColor` | `ColorValue`                         | `overlay`  | 弹层颜色。默认使用 `overlay` 主题色（glass 主题下为原生材质）             |
| `backgroundBlur`  | `BackgroundBlur`                     | -          | 模糊的弹层材质（iOS）                                                     |
| `header`          | `React.ReactNode`                    | -          | 固定在弹层顶部的内容。固定的 `BottomSheet.Header` 会取代它                |
| `footer`          | `React.ReactNode`                    | -          | 固定在弹层底部的内容。固定的 `BottomSheet.Footer` 会取代它                |
| `scrollableRef`   | `RefObject<ScrollViewInstance \| …>` | -          | 弹层内滚动视图的 ref                                                      |
| `insetAdjustment` | `'automatic' \| 'never'`             | -          | 设为 `'never'` 时弹层不再添加底部安全区                                   |
| `animation`       | `AnimationRootDisableAll`            | -          | `"disable-all"` 禁用弹层内容中的动画（含子级）                            |
| `onWillPresent`   | `(event) => void`                    | -          | 弹层呈现前调用                                                            |
| `onDidPresent`    | `(event) => void`                    | -          | 弹层呈现后调用                                                            |
| `onDidDismiss`    | `(event) => void`                    | -          | 弹层关闭后调用，无论以何种方式关闭                                        |
| `onDetentChange`  | `(event) => void`                    | -          | 弹层停靠到另一个停靠点时调用                                              |

#### Ref 方法（`BottomSheetRef`）

| method                       | description                                    |
| ---------------------------- | ---------------------------------------------- |
| `present(index?, animated?)` | 在索引为 `index` 的停靠点呈现弹层（默认 `0`）  |
| `resize(index)`              | 将已呈现的弹层移动到索引为 `index` 的停靠点    |
| `dismiss(animated?)`         | 关闭弹层及堆叠在其上的所有弹层                 |
| `dismissStack(animated?)`    | 仅关闭堆叠在其上的弹层                         |

## Hooks

### useBottomSheetAnimation

返回在 UI 线程上更新的实时弹层值。必须在 `BottomSheet` 内调用。

| property           | type                   | description                                              |
| ------------------ | ---------------------- | -------------------------------------------------------- |
| `animatedPosition` | `SharedValue<number>`  | 弹层顶边距屏幕顶部的 Y 偏移                              |
| `animatedIndex`    | `SharedValue<number>`  | 以连续值表示的停靠点索引（位于屏幕外时为 `-1`）          |
| `animatedDetent`   | `SharedValue<number>`  | 当前停靠点，以可用高度的比例（`0`–`1`）表示              |
| `progress`         | `DerivedValue<number>` | 位于屏幕外时为 `0`，静止后为 `1`，移动过程中介于两者之间 |

## 从旧版 BottomSheet 迁移

旧版 `BottomSheet` 基于 `@gorhom/bottom-sheet` 构建，现已不再使用该库。

| 变更前                                            | 现在                                                         |
| ------------------------------------------------- | ------------------------------------------------------------ |
| `isOpen` / `onOpenChange` / `BottomSheet.Trigger` | `ref.present()` / `ref.dismiss()` 与 `onDidDismiss`          |
| `BottomSheet.Portal`、`BottomSheet.Overlay`       | 不再需要：弹层以原生方式呈现，并自行遮暗（或模糊）背景       |
| `BottomSheet.Content` 上的弹层属性                | 改为设置在 `BottomSheet` 本身；`className` 仍在 `Content` 上 |
| `snapPoints={['40%', '80%']}`                     | `detents={[0.4, 0.8]}`                                       |
| `enableDynamicSizing`                             | `detents={['auto']}`（默认值）                               |
| `enablePanDownToClose={false}`                    | `dismissible={false}`                                        |
| `BottomSheetScrollView` / `BottomSheetFlatList`   | `ScrollView` / `FlatList` 配合 `scrollableRef`               |
| `BottomSheetFooter` / `footerComponent`           | `<BottomSheet.Footer isSticky>` 或 `footer` 属性             |
| `useBottomSheetAwareHandlers`                     | 已移除：弹层以原生方式处理键盘                               |
| `useBottomSheet()`                                | 已移除：改为持有弹层的 ref                                   |
