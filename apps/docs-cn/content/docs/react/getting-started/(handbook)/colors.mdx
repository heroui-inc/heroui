HeroUI 使用 CSS 变量来管理颜色，可在浅色和深色主题之间自动切换。所有颜色均采用 `oklch` 色彩空间，以获得更平滑的色彩过渡。

<Callout type="info">
  **想要创建你自己的主题？** 试试 [主题构建器](/themes)，以可视化方式自定义颜色、圆角、字体等，然后导出 CSS 用于你的项目。
</Callout>

## 工作原理

HeroUI 的颜色系统构建于 Tailwind CSS v4 的主题之上。当你导入 `@heroui/styles` 时，它会使用 Tailwind 的内置调色板，并将其映射到语义化变量。

**命名规则：**
- 不带后缀的颜色用作背景（例如 `--accent`）
- 带 `-foreground` 后缀的颜色用于该背景上的文本（例如 `--accent-foreground`）

**用法：**
```html
<html class="light" data-theme="light">
  <body class="bg-background text-foreground">
    <!-- Your app -->
  </body>
</html>
```

```tsx
// This gives you the right background and text colors
<div className="bg-accent text-accent-foreground">Hello</div>
```

## 如何使用颜色

**在你的组件中：**
```jsx
<div className="bg-background text-foreground">
  <button className="bg-accent text-accent-foreground hover:bg-accent-hover">
    Click me
  </button>
</div>
```

**在 CSS 文件中：**

```css title="global.css"
/* Direct CSS variables */
.my-component {
  background: var(--accent);
  color: var(--accent-foreground);
  border: 1px solid var(--border);
}

/* With @apply and @layer */
@layer components {
  .button {
    @apply bg-accent text-accent-foreground;

    &:hover,
    &[data-hovered="true"] {
      @apply bg-accent-hover;
    }

    &:active,
    &[data-pressed="true"] {
      @apply bg-accent-hover;
      transform: scale(0.97);
    }
  }
}
```

## 自定义颜色

**覆盖现有颜色：**

```css
:root {
  /* Override default colors */
  --accent: oklch(0.7 0.15 250);
  --success: oklch(0.65 0.15 155);
}

[data-theme="dark"] {
  /* Override dark theme colors */
  --accent: oklch(0.8 0.12 250);
  --success: oklch(0.75 0.12 155);
}
```

**提示：** 你可以在 [oklch.com](https://oklch.com) 转换颜色。

**添加你自己的颜色：**

```css
:root,
[data-theme="light"] {
  --info: oklch(0.6 0.15 210);
  --info-foreground: oklch(0.98 0 0);
}

.dark,
[data-theme="dark"] {
  --info: oklch(0.7 0.12 210);
  --info-foreground: oklch(0.15 0 0);
}

/* Make the color available to Tailwind */
@theme inline {
  --color-info: var(--info);
  --color-info-foreground: var(--info-foreground);
}
```

现在你可以使用它：

```tsx
<div className="bg-info text-info-foreground">Info message</div>
```

> **注意**：要进一步了解主题变量以及它们在 Tailwind CSS v4 中的工作方式，请参阅 [Tailwind CSS 主题文档](https://tailwindcss.com/docs/theme)。


## 快速提示

- 始终使用颜色变量，而不是硬编码的色值
- 使用前景/背景配对，以获得良好的对比度
- 在浅色和深色模式下都进行测试
- 系统会自动遵循用户的主题偏好
