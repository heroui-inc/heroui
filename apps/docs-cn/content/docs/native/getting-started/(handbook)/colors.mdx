HeroUI Native 使用 CSS 变量定义颜色，并可在浅色与深色主题间自动切换。所有颜色采用 `oklch` 色彩空间，便于获得更平滑的过渡。

## 工作原理

HeroUI Native 的颜色系统建立在 [Tailwind CSS v4](https://tailwindcss.com/docs/theme) 主题之上，并通过 [Uniwind](https://uniwind.dev/) 接入。导入 `heroui-native/styles` 时，会使用 Tailwind 内置调色板并映射到语义化变量。

**命名约定：**

- 无后缀色一般为背景色（如 `--accent`）
- 带 `-foreground` 的一般为该背景上的文字色（如 `--accent-foreground`）

**用法：**

```tsx
import { View, Text } from 'react-native';

// 同时获得合适的背景与文字色
<View className="bg-background flex-1">
  <View className="bg-accent p-4 rounded-lg">
    <Text className="text-accent-foreground">你好</Text>
  </View>
</View>;
```

## 如何使用颜色

**在组件中：**

```tsx
import { View, Text } from 'react-native';
import { Button } from 'heroui-native';

<View className="bg-background flex-1 p-4">
  <Text className="text-foreground mb-4">内容</Text>
  <Button variant="primary" className="bg-accent">
    <Button.Label className="text-accent-foreground">点我</Button.Label>
  </Button>
</View>;
```

**在 CSS 文件中：**

```css title="global.css"
/* 直接使用 CSS 变量 */
.container {
  flex: 1;
  background-color: var(--accent);
  width: 50px;
  height: 50px;
  border-radius: var(--radius);
}
```

## 自定义颜色

**覆盖已有颜色：**

```css
@layer theme {
  @variant light {
    /* 覆盖默认颜色 */
    --accent: oklch(0.65 0.25 270); /* 自定义靛蓝强调色 */
    --success: oklch(0.65 0.15 155);
  }

  @variant dark {
    /* 覆盖深色主题颜色 */
    --accent: oklch(0.65 0.25 270);
    --success: oklch(0.75 0.12 155);
  }
}
```

**提示：** 可在 [oklch.com](https://oklch.com) 转换颜色。

**添加自定义颜色：**

```css
@layer theme {
  @variant light {
    --info: oklch(0.6 0.15 210);
    --info-foreground: oklch(0.98 0 0);
  }

  @variant dark {
    --info: oklch(0.7 0.12 210);
    --info-foreground: oklch(0.15 0 0);
  }
}

@theme inline {
  --color-info: var(--info);
  --color-info-foreground: var(--info-foreground);
}
```

随后即可使用：

```tsx
import { View, Text } from 'react-native';

<View className="bg-info p-4 rounded-lg">
  <Text className="text-info-foreground">提示信息</Text>
</View>;
```

> **说明**：更多主题变量及其在 Tailwind CSS v4 中的工作方式，见 [Tailwind CSS Theme 文档](https://tailwindcss.com/docs/theme)。

## useThemeColor 钩子

`useThemeColor` 已支持一次选取多种颜色，便于复杂主题场景。

**多色选取：**

可一次读取多个相关颜色，适合需要成组使用的场景：

```tsx
import { useThemeColor } from 'heroui-native';

// 一次选取多个颜色
const [accent, accentForeground, success, danger] = useThemeColor([
  'accent',
  'accentForeground',
  'success',
  'danger',
]);

// 使用选取的颜色
<View style={{ backgroundColor: accent }}>
  <Text style={{ color: accentForeground }}>强调色文字</Text>
</View>;
```

该能力在需要同时读取并应用多色时，可减少重复调用、简化主题相关代码。

## 实用建议

- 尽量使用颜色变量，避免硬编码色值
- 前景/背景成对使用以保证对比度
- 在浅色与深色模式下分别测试
- 系统会尊重用户的主题偏好设置
